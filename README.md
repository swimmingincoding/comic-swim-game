# 🏊‍♂️ 3D 올림픽 50m 자유형 코믹 수영 배팅 게임 (Comic Swim Game)

실제 올림픽 공식 50m 규격 경기장에서 펼쳐지는 흥미진진한 예측불가 3D 수영 배팅 게임입니다!  
8명의 영자가 자유형으로 출발하지만, **오직 1등만 유일하게 정상적으로 수영해서 들어오며** 나머지 7명은 레이스 도중 포복절도할 돌발 상황을 겪게 됩니다.

---

## 🌟 주요 특징

### 1. 사실적인 3D 올림픽 경기장 (Three.js WebGL)
- **공식 올림픽 규격 50m 수영장**: 10개 레인 (각 폭 2.5m, 총 폭 25m, 수심 2.5m).
- **실제 사용 8개 레인**: 양 끝(0번, 9번 레인)은 완충 레인으로 비워두고, 가운데 1~8번 레인에서 경기 진행.
- **올림픽 디테일**: 바닥 T자 마커, FINA 규격 색상 부표 로프(5m/15m/25m 마커 포함), 10개 스타트대(경사 발판 및 백스트로크 핸들), 노란색 감응 터치패드, 물결 셰이더, 수중 조명 및 아레나 스탠드.
- **실시간 LED 점보트론 전광판**: 경기 타이머, 실시간 선두 주자, 코믹 긴급 속보 자막 실시간 렌더링.

### 2. 8명의 개성 넘치는 수영 영자 & 위장 스탯
- 남/녀, 청년/노인, 근육질/너드 등 다양한 체형과 비주얼 (피부톤, 수영복, 수모, 수경).
- **예측 불가 페이크 스탯**: 속도 98의 국대 에이스도, 약수터 박춘삼 할아버지도 결과는 순수 랜덤! 끝날 때까지 1등이 누가 될지 전혀 알 수 없습니다.
  1. **레인 1**: "새벽 약수터 전설" 박춘삼 (74세, 남) - 백발의 마스터즈
  2. **레인 2**: "돌고래 요정" 이수민 (23세, 여) - 우아한 아티스틱 스위머
  3. **레인 3**: "헬스장 3대 600" 마동철 (34세, 남) - 파워 광배근 상남자
  4. **레인 4**: "국가대표 에이스" 김태환 (21세, 남) - 강력한 우승 후보
  5. **레인 5**: "복덕방 아쿠아로빅" 최영자 (67세, 여) - 동네 수영장 지킴이
  6. **레인 6**: "유튜브 3일 독학" 정민우 (27세, 남) - 뿔테 수경의 너드
  7. **레인 7**: "폭풍 발차기 여대생" 강하나 (22세, 여) - 모터보트급 킥
  8. **레인 8**: "해병대 특수수색대" 오필승 (32세, 남) - 거친 파도를 뚫는 상남자

### 3. 포복절도 코믹 돌발 상황 시스템 (Comic Incidents)
- **규칙**: 1등만 유일하게 완벽한 정석 자유형으로 완주! 나머지 7명은 레이스 도중 (13m ~ 42m 지점) 골때리는 사건 발생:
  - 🛑 **로프 잡고 휴식**: "아이고 힘들어..." 레인 부표를 두 손으로 붙잡고 헉헉거리며 멈춤
  - ↩️ **가스불 유턴 (역주행)**: "집에 가스불 켜놓고 왔다!" 180도 회전하여 출발선으로 맹렬히 헤엄쳐 돌아감
  - 🐢 **체력 방전 (거북이 수영)**: 폭풍 질주하다가 연기 푸시식 나며 시속 0.2km/h 목욕탕 개헤엄으로 감속
  - ⚡ **다리에 쥐 남!**: "아악 내 다리!" 물 위에 대자로 벌렁 누워 다리 잡고 뱅글뱅글 회전
  - 👓 **물안경 분실**: 수경이 벗겨져 목에 걸리고 앞이 안 보여 제자리에서 허우적거리며 더듬더듬
  - 🎉 **설레발 조기 세레머니**: 1등인 줄 착각하고 결승선 10m 앞에서 관중석에 양손 번쩍 환호하다 추월당함
  - 💥 **접영 흉내 배치기**: 접영 웨이브 뛰려다 수면에 철퍽! 배치기 후 기절 모드 표류
- **돌발 연출**: 머리 위 3D 코믹 말풍선 이모지 팝업 + 중계 속보 자막 + 코믹 효과음!

### 4. 경마 스타일 배팅 & 보상 시스템
- 초기 지원 코인: **10,000 C** (소진 시 상단 '+' 버튼으로 무료 리필 가능).
- **등수 근접 보상 체계**:
  - 🥇 **1등 적중**: 배팅액의 **8.0배** 대박!
  - 🥈 **2등**: 배팅액의 **2.5배**
  - 🥉 **3등**: 배팅액의 **1.5배**
  - 🏅 **4등**: 배팅액의 **1.0배 (원금 회수)**
  - 5~8등: 배팅 실패
- 배팅 칩 버튼 (`+100`, `+500`, `+1,000`, `+5,000`, `절반`, `올인`).

### 5. 방송 중계 스타일 다중 카메라 시점
- 📺 **방송 중계 (Broadcast)**: 선두 그룹을 측면 상공에서 부드럽게 팔로우하는 레일 트래킹 뷰
- 🎯 **내 선수 밀착 (My Bet)**: 내가 배팅한 선수의 등 뒤에서 표정과 돌발 상황을 초근접 관전
- 🏟️ **전경 와이드 (Overview)**: 50m 경기장 10개 레인 전체를 한눈에 내려다보는 스타디움 뷰
- 🏁 **결승선 터치 (Finish)**: 결승 터치패드 정면에서 골인 순간을 확인하는 정면 뷰

### 6. Web Audio API 사운드 시스템
- 외부 음원 다운로드 없이 브라우저 자체 오디오 신디사이저로 모든 사운드 합성:
  - 심판 휘슬 호각음
  - 올림픽 공식 1kHz 스타트 비프 버저
  - 다이빙 입수 묵직한 물보라 쾅! 사운드
  - 유턴 띠요옹, 바람 빠지는 피유우, 전기 찌릿, 배치기 찰싹 등 코믹 SFX
  - 터치패드 골인 버저 및 승리 팡파르

## 🚀 실행 방법

```bash
# 종속성 설치
npm install

# 개발 서버 실행 (기본 포트: 3000)
npm run dev

# 프로덕션 빌드
npm run build
```

브라우저에서 `http://localhost:3000/` 접속 후 원하는 선수에 배팅하고 경기를 관전하세요!
